# CVForge AI

CVForge AI is a public prototype for an ATS-focused CV and job-application workspace.

## Prototype capabilities
- CV dashboard and CV manager
- Job-targeting / ATS optimization workflow UI
- LinkedIn optimization interface
- Pricing and billing interface
- Responsive React/Vite frontend

## Important status
This repository is a **prototype**, not a production authentication or billing system. The current sign-in flow is local/demo authentication, CV data is mock data, and billing is UI-only.

Before production, replace these with server-backed authentication, persistent storage, secure document handling, a real ATS/AI service, payment integration, and privacy/deletion workflows.

## Local development
```bash
npm install
npm run dev
```
